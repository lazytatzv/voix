# Voix

> **Linuxネイティブで動く、Googleデザインのシンプルな音声合成＆動画字幕スタジオ**

録画した動画（ゲーム実況・作業動画等）に合わせて、VOICEVOXや合成音声を楽に配置・自動字幕入れ・MP4書き出しができるデスクトップアプリ（Tauri v2 + React 19 + TypeScript + Rust）です。

---

## 🚀 クイックスタート

### 1. VOICEVOX の起動 (Docker)
このディレクトリに同梱されている Docker Compose で一発起動できます。

```bash
# CPU版の起動
./voicevox.sh start

# NVIDIA GPU版の起動 (GPUをお持ちの場合)
./voicevox.sh start gpu

# 停止
./voicevox.sh stop
```
起動すると `http://localhost:50021` でAPIが利用可能になります。

### 2. アプリの起動

```bash
# 依存関係のインストール
pnpm install

# 開発モードでアプリ起動
pnpm tauri dev
```

## ✨ 主な機能

- **動画ドラッグ＆ドロップ & プレビュー**: 撮った動画を背景に配置し、YouTube風の快適プレイヤーで再生。
- **AI 音声から自動字幕（無音検出）**: 動画内の喋っている区間（ミリ秒単位）を自動特定してセリフブロックを配置。
- **台本・チャット式入力**: セリフを打つだけで、VOICEVOX音声・字幕・タイムラインが全自動連動。
- **クリップ微調整**:
  - 話速（Speed: 0.7x 〜 1.8x）
  - 音高（Pitch）
  - クリップ分割（✂️）＆ 複製（📋）
- **高速MP4書き出し**: バックエンドの FFmpeg によるハードウェアアクセラレーション動画レンダリング。
- **プラグイン式TTS**: VOICEVOXだけでなく、COEIROINKやAivisSpeechなど互換エンジンにも対応。
- **自動保存 & プロジェクト保存**: 作業中のデータは自動バックアップされ、`.myymmp` ファイルでの保存・共有も可能。
